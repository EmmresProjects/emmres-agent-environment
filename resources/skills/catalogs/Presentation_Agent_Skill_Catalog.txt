How to Use This Catalog

- Each entry is an independent candidate capability. A future catalog builder may combine tightly related entries, split high-risk entries into smaller skills, or package several entries behind one orchestrator.

- Skill names are written as action-oriented capability labels. Descriptions define the intended execution boundary and expected result, not implementation details.

- The catalog deliberately includes inspection, creation, editing, validation, recovery, accessibility, governance, export, automation, and skill-management scenarios so an agent can operate end to end.

- When implementing these skills, define explicit triggers, inputs, outputs, exclusions, dependencies, deterministic checks, failure handling, and clean-state tests.

Category 1: Presentation Intake and Structural Inspection

Category purpose: Understand the real deck before changing it.

1. Skill Name: Presentation Package Profiler

  Description: Inspects slide count, canvas dimensions, aspect ratio, masters, layouts, sections, notes, media, relationships, and package health before any edit.

2. Skill Name: Slide Object Census

  Description: Counts and classifies placeholders, text boxes, shapes, connectors, tables, charts, media, groups, and hidden objects per slide.

3. Skill Name: Master and Layout Mapper

  Description: Maps every slide to its master and layout, identifies unused or duplicated layouts, and separates inherited formatting from local overrides.

4. Skill Name: Editable Object Detector

  Description: Distinguishes native editable objects from flattened screenshots, imported diagrams, and rasterized compositions.

5. Skill Name: Hidden Content Inspector

  Description: Finds hidden slides, off-canvas objects, invisible text, zero-size objects, covered elements, and content with full transparency.

6. Skill Name: Notes and Metadata Auditor

  Description: Reviews speaker notes, comments, document properties, author fields, custom XML, revision data, and privacy-sensitive metadata.

7. Skill Name: Embedded Asset Enumerator

  Description: Lists embedded images, fonts, audio, video, OLE objects, attachments, and external links with file type and usage location.

8. Skill Name: Slide Family Classifier

  Description: Groups slides into recurring visual families such as title, divider, content, diagram, checklist, media, appendix, and closing slides.

9. Skill Name: Object Naming Normalizer

  Description: Renames generic objects into stable semantic identifiers so later automation can target elements reliably.

10. Skill Name: Presentation Dependency Scanner

  Description: Detects linked files, unavailable fonts, external media, broken relationships, unsupported features, and environment-sensitive dependencies.

11. Skill Name: Deck Baseline Snapshot

  Description: Creates a reproducible pre-edit inventory of structure, geometry, styles, and rendered appearance for later regression comparison.

12. Skill Name: Presentation Intent Boundary Detector

  Description: Separates audience-facing content from authoring instructions, production notes, placeholders, and template artifacts.
