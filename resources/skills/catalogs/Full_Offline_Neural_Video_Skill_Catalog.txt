Catalog Scope

This catalog covers text-to-video, image-to-video, video-to-video, character animation, talking avatars, lip sync, interpolation, restoration, upscaling, neural editing, audio, captions, encoding, validation, offline packaging, safety, rights, and lifecycle operations.

Model options include Stable Video Diffusion, AnimateDiff, CogVideoX, HunyuanVideo, Wan, LTX-Video, Mochi, LivePortrait, Wav2Lip, RIFE, Real-ESRGAN, and additional open or locally deployable components. The catalog does not bundle weights or assert that every model permits redistribution.

A complete offline runtime requires pre-downloaded model files, wheels, native libraries, codecs, documentation, presets, and tests. Model size, GPU memory, license, architecture, and runtime compatibility must be verified before air-gapped use.

Recommended Skill Architecture

Control-plane skill: Selects generation mode, model, hardware profile, presets, safety gates, temporal checks, audio path, and delivery format.

Model packs: Contain model-specific loaders, configurations, licenses, checksums, memory strategies, known limits, and regression fixtures.

Execution skills: Perform generation, animation, restoration, editing, assembly, audio mixing, captioning, and encoding through deterministic local interfaces.

Validation skills: Independently inspect decoding, frame integrity, temporal consistency, identity, lip sync, audio sync, captions, color, loudness, playback, and offline behavior.

Governance skills: Preserve consent, provenance, disclosure, licenses, allowed uses, version history, clean-state tests, and reproducible acceptance evidence.

Core Acceptance Reference

- A clean sandbox installs the runtime, local wheels, native libraries, codecs, model files, configurations, and presets without first-run downloads or API keys.

- Reference text-to-video, image-to-video, video-to-video, talking-avatar, lip-sync, interpolation, upscaling, restoration, and assembly jobs produce playable outputs within declared hardware and timeout budgets.

- Final media passes decode, duration, resolution, frame-rate, missing-frame, duplicate-frame, corrupt-frame, flicker, temporal-consistency, identity, lip-sync, audio-sync, loudness, subtitle-timing, file-size, and seekability checks.

- Every model, voice, music track, sound effect, reference image, reference video, and generated output carries the required license, consent, provenance, allowed-use, version, and checksum records.

- Low-memory fallbacks, offloading, tiling, quantization, cancellation, resume, cleanup, and out-of-memory recovery are tested rather than assumed.

- Human review confirms motion naturalness, character consistency, prompt adherence, narrative coherence, audio quality, accessibility, cultural fit, and absence of unacceptable artifacts.

Catalog Design Notes

- Keep model-neutral orchestration separate from model-specific loaders and memory strategies.

- Freeze a passing reference case for every major mode before changing model, runtime, driver, CUDA, quantization, scheduler, codec, or encoding settings.

- Treat temporal quality as a first-class acceptance dimension. A technically decodable video can still fail because of identity drift, flicker, object mutation, discontinuous motion, or incoherent camera paths.

- Never distribute weights, voices, or reference media until license and redistribution permission are confirmed. Require explicit consent for likeness animation, lip sync, voice cloning, or talking-avatar use.

- Package only the catalog documents requested here. Actual model bundles can be hundreds of gigabytes and must be assembled later for a defined hardware and licensing target.
