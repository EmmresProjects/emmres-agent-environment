ULTIMATE TRANSLATION

Skill Catalog

A comprehensive capability catalog for multilingual translation, localization, transcription, subtitling, media, software, games, documents, and quality assurance.

Catalog purpose. Use these entries as a blueprint for separate, composable Skills. Each Skill should accept real user assets, preserve source structure, expose uncertainty, use human review for high-risk content, and return validated, editable deliverables. The catalog intentionally separates capabilities so an agent can invoke only the smallest relevant Skill or orchestrate several Skills for an end-to-end project.

Category 1: Core Translation and Language Intelligence

1. Skill Name: Ultimate Translator

Description: Translate text of any practical length across languages while preserving meaning, intent, tone, terminology, structure, numbers, names, and formatting. Detect source languages, handle mixed-language content, explain uncertainties, and produce literal, natural, formal, or audience-adapted versions.

2. Skill Name: Language Auto-Detection and Segmentation

Description: Identify languages, scripts, dialect shifts, code-switching, borrowed words, and untranslated spans at sentence or token level. Split multilingual inputs into translation-ready segments without damaging context.

3. Skill Name: Context-Aware Long-Form Translator

Description: Translate books, reports, manuals, archives, and large collections in ordered chunks with rolling context, chapter memory, terminology consistency, cross-reference preservation, and resumable progress.

4. Skill Name: Meaning and Intent Preserver

Description: Protect implied meaning, emotional force, politeness, humor, ambiguity, and speaker intent instead of translating words mechanically. Flag meanings that cannot be carried directly into the target language.

5. Skill Name: Register and Tone Adapter

Description: Translate into formal, casual, academic, technical, legal, friendly, persuasive, child-friendly, or brand-specific language while retaining the original message.

6. Skill Name: Dialect and Regional Variant Translator

Description: Translate between regional forms such as European and Brazilian Portuguese, Latin American and Peninsular Spanish, Simplified and Traditional Chinese usage, and other locale-specific variants.

7. Skill Name: Transliteration and Script Converter

Description: Convert names and text between writing systems using configurable standards, pronunciation-based rendering, reversible transliteration where possible, and side-by-side native script.

8. Skill Name: Low-Resource Language Assistant

Description: Support scarce-resource languages through careful segmentation, glossing, user-provided dictionaries, parallel examples, confidence labels, and human-review queues rather than inventing certainty.

9. Skill Name: Pidgin, Creole, and Vernacular Translator

Description: Handle vernacular grammar, nonstandard spelling, community expressions, and mixed vocabularies while preserving identity and avoiding forced standardization.

10. Skill Name: Parallel Bilingual Output Builder

Description: Produce source-target parallel text by sentence, paragraph, table row, or timecode for review, study, publishing, and translation-memory import.
