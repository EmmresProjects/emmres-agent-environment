MEDIA INTELLIGENCE
SKILL CATALOG

A comprehensive capability catalog for agents that interpret, understand, search, transform, validate, and govern video, images, sound, speech, music, and multimodal media.

250 proposed skills across 25 categories

  Prepared as a planning catalog. These entries define reusable skill concepts, not implemented skill packages.

How to Use This Catalog

- Use each entry as a seed for a separate agent skill, or combine tightly related entries into a skill family with progressive references and specialist tools.

- For implementation, define accepted inputs, required outputs, tool and connector dependencies, confidence rules, privacy constraints, failure behavior, validation tests, and human-review triggers.

- Keep media analysis evidence-grounded. Findings should link to source files, timestamps, frames, regions, speakers, or metadata, and should distinguish observations from interpretations.

- Apply non-destructive processing by default. Preserve originals, record transformations, and validate generated or edited outputs through the recipient’s actual use path.

Catalog Design Principles

- Multimodal, not transcript-only

- Timecoded and spatially grounded

- Confidence-aware and reviewable

- Privacy, consent, rights, and accessibility by design

- Modular, composable, restartable, and testable

- Useful across normal, low-quality, long-form, multilingual, live, and sensitive scenarios

1. Multimodal Intake and Media Routing

10 proposed skills

1. Skill Name: Universal Media Intake

  Description: Accept, identify, and route mixed image, video, audio, music, document, subtitle, stream, archive, and sensor files while preserving source order and relationships.

2. Skill Name: Media Type and Codec Detector

  Description: Determine container, codec, encoding, bit depth, channel layout, frame rate, color space, resolution, duration, and likely decoder requirements before processing.

3. Skill Name: Corrupt Media Triage

  Description: Detect truncation, damaged headers, missing indexes, broken frames, silent channels, malformed metadata, and partial uploads, then recommend safe repair or recovery paths.

4. Skill Name: Archive and Package Explorer

  Description: Inspect ZIP, TAR, project bundles, camera cards, and editing packages; inventory nested assets and map dependency links without losing directory context.

5. Skill Name: Batch Media Organizer

  Description: Group large media collections by source, date, subject, event, format, similarity, and processing priority, with duplicate-aware naming and manifests.

6. Skill Name: Streaming Source Intake

  Description: Connect to live or recorded streams, segment them safely, monitor continuity, and create checkpoints for later analysis.

7. Skill Name: Camera Roll Curator

  Description: Scan personal or project camera rolls, cluster bursts and events, flag poor captures, and surface representative images while keeping originals untouched.

8. Skill Name: Cross-File Relationship Mapper

  Description: Link thumbnails, proxies, originals, sidecar files, captions, stems, transcripts, and project files into a coherent asset graph.

9. Skill Name: Media Normalization Planner

  Description: Plan non-destructive conversions into analysis-ready formats while retaining originals, technical metadata, timing, and provenance.

10. Skill Name: Input Safety Scanner

  Description: Screen media for decompression bombs, malformed payloads, suspicious macros, hidden executables, and other unsafe ingestion conditions before deeper processing.
