SPREADSHEET, DATA & FINANCE
SKILL CATALOG

A comprehensive catalog of reusable agent capabilities for spreadsheet creation, editing, forms, data management, analytics, accounting, finance, modeling, visualization, automation, quality, and governance.

340 proposed skills across 34 categories

  Planning catalog only. The entries describe skill concepts and expected scope, not prebuilt skill packages.

How to Use This Catalog

- Use each entry as a standalone skill idea or combine closely related entries into a modular skill family with a compact entrypoint and detailed references.

- For each implemented skill, specify supported file formats, inputs, outputs, calculation rules, locale, accounting policy, connectors, permissions, performance limits, and human-review triggers.

- Preserve raw inputs and edit non-destructively. Record transformations, assumptions, formulas, mappings, versions, and exceptions so every output can be traced and repaired.

- Validate workbook structure, calculations, data quality, visual layout, accessibility, security, print or PDF output, and recipient usability before delivery.

Catalog Design Principles

- Correct calculations with visible control checks

- Editable and compatible spreadsheet outputs

- Clear inputs, calculations, outputs, and documentation

- Reproducible data transformations and financial logic

- Professional visual design with accurate chart placement

- Privacy, access, governance, and safe automation

- Human review for consequential financial, workforce, tax, regulatory, and predictive uses
