Purpose and Scope

This catalog defines a broad family of reusable skills for an “Ultimate Text Editor/Maker/Creator.” It is a capability catalog, not a set of implemented skill packages. Each entry is intentionally scoped so that a future builder can turn it into one focused skill, combine related entries into a suite, or use the catalog as a roadmap for an agent.

The catalog covers text creation, editing, Unicode, ASCII and legacy encodings, symbols, emoji, languages, text art, structured formats, code text, retrieval, professional writing, creative work, analysis, accessibility, security, media text, automation, specialist notation, and orchestration. “All” and “infinite” are treated as extensible goals: the future agent should retrieve current authoritative tables and standards when knowledge is version-sensitive rather than claiming a permanently complete internal list.

Recommended Catalog Fields for Future Builds

- Skill name and trigger description

- Accepted inputs and required context

- Output formats and strict constraints

- Tools, connectors, standards, and reference sources

- Validation checks, edge cases, and failure behavior

- Security, privacy, accessibility, and localization rules

- Examples, test fixtures, and quality rubric

- Dependencies and related skills
