How to Use This Catalog

- Treat every entry as an independent candidate skill or as a component that a future orchestrator may combine with adjacent skills.

- When implementing a skill, define triggers, exclusions, accepted file types, exact inputs and outputs, side effects, permissions, platform requirements, failure meanings, repair steps, and tests.

- Microsoft Word differs by Windows, Mac, web, mobile, license, account, document type, selection, and administrator policy. Implemented skills should detect the active environment rather than assume a command exists.

- Prefer named styles, native Word structures, reversible edits, last-known-good copies, and artifact-level validation through rendering, reopening, printing, or export.
