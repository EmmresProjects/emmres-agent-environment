# Upload checklist

- [ ] Put builder scripts in `Build/`.
- [ ] Put requirements in `Requirements/`.
- [ ] Put component documentation or approved redistributable files in `Components/`.
- [ ] Update versions, official sources, licenses, and SHA-256 checksums.
- [ ] Keep the generated installed environment outside normal Git.
- [ ] Remove credentials and private data.
- [ ] Configure Git LFS before committing large binaries.
- [ ] Update every relevant page under `docs/`.
- [ ] Commit and push with GitHub Desktop.
- [ ] Enable GitHub Pages from `main` and `/docs`.
- [ ] Test the published site and add it to Agent Builder.
