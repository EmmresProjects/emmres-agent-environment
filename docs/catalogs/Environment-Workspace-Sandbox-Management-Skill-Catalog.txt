A comprehensive catalog of composable agent skills for discovering, organizing, creating, installing, operating, validating, recovering, cleaning, and governing complete AI workspaces and execution environments.

  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Catalog purpose. This document proposes focused skills for later implementation. It does not contain implemented skills. Each skill should preserve originals, use least privilege, prefer reversible operations, isolate risky work, record dependencies, validate actual outputs, clean temporary state, and deliver only requested artifacts.
  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Workspace Management Principles

- Inspect the real workspace before changing it. Build a verified map of files, tools, environments, resources, and dependencies.

- Preserve source materials and user uploads. Use working copies, snapshots, backups, atomic writes, and explicit approval for destructive actions.

- Install the smallest trusted dependency set into isolated, reproducible environments instead of mutating global state by default.

- Separate inputs, sources, scratch work, caches, tests, builds, candidates, and final deliverables with clear ownership and lifecycle rules.

- Use checks that can fail: structure, semantics, boundaries, integrations, regression, clean-state rebuild, presentation, and recipient handoff.

- After completion, stop task-owned processes, remove temporary secrets and residue, retain required recovery state, and verify the final package.
