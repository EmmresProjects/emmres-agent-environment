How to use this catalog

Each entry is a candidate reusable agent skill. A future skill implementation should define trigger conditions, required inputs, safe permissions, provider-specific references, deterministic scripts where useful, validation gates, rollback behavior, and evidence-producing outputs. Skills that can change production should default to preview, least privilege, explicit approvals, bounded scope, and post-change verification.

Catalog design principles

- Provider-aware but portable across AWS, Microsoft Azure, Google Cloud, hybrid, and self-hosted environments.

- Safe by default: preview changes, protect secrets, preserve rollback, and verify the final state.

- Production-ready: include testing, monitoring, ownership, incident response, recovery, and documentation.

- Composable: narrow skills can be combined into larger deployment, migration, audit, or recovery workflows.

- Evidence-driven: produce concise plans, diffs, test results, logs, dashboards, and audit-ready records.
