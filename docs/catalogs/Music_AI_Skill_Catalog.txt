Music AI Orientation

- Music-generation systems can model patterns in audio, symbolic music, lyrics, and descriptive text. Useful skill designs should keep the model, dataset, prompt, output, editing, and validation stages separate so each stage can be inspected and improved.

- A strong creation workflow usually begins with a creative brief, then produces controlled iterations, selects the best material, separates or rebuilds stems when needed, edits inside a digital audio workstation, and finishes with mixing, mastering, metadata, rights review, and delivery checks.

- Generated audio should remain editable. Preserve prompts, seeds or settings when available, source files, stems, MIDI, lyrics, session versions, approvals, rights notes, and final masters.

- Human review is essential for musical coherence, unwanted imitation, deceptive voice use, clipping, artifacts, incorrect lyrics, cultural context, accessibility, licensing, and release readiness.

Recommended Skill Construction Pattern

- Define a narrow trigger and the exact music task the skill owns.

- Specify inputs such as audio, MIDI, lyrics, score, prompt, references, tempo, key, meter, stems, target platform, and rights status.

- Return editable outputs plus a concise decision log, not only a flattened audio file.

- Use reference files for genres, instruments, production notes, technical delivery profiles, rights guidance, and approved terminology.

- Add scripts only for deterministic work such as analysis, conversion, metadata validation, batch processing, or conformance checks.

- End with listening checks, technical measurements, artifact review, rights and consent review, and a clean handoff.

Implementation Checklist for Any Selected Music Skill

- Define expected input formats, sample rates, bit depths, channel layouts, tempo and key conventions, and maximum duration.

- Define creative controls, prohibited imitation behavior, voice consent requirements, and cultural context rules.

- Define editable intermediate outputs such as stems, MIDI, MusicXML, lyrics, presets, automation, cue sheets, or session files.

- Define objective checks such as clipping, true peak, loudness, phase, silence, file integrity, metadata, and naming.

- Define listening checks for form, groove, tuning, intelligibility, artifacts, transitions, emotional fit, and translation.

- Define rights, licenses, credits, provenance, disclosure, retention, and release approval.

- Test normal, empty, malformed, repeated, extreme, conflicting, and unsupported inputs.

- Preserve a known-passing reference project and rerun affected checks after every repair.

- Open the final files in the recipient workflow and verify the ZIP or delivery package from a clean state.

- Keep the skill compact and move detailed references, templates, datasets, and scripts into clearly named supporting folders.
