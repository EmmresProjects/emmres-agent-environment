A comprehensive catalog of reusable agent skills for source code, machine code, executables, archives, structured data, protocols, firmware, recovery, validation, repair, and preservation.

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Catalog purpose. This document proposes distinct, composable skills. It is not a package of implemented skills. Each entry is scoped so a stronger agent can later turn it into a focused SKILL.md with scripts, references, assets, tests, read-only defaults, and reproducible reporting.
  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Design Principles

- Preserve originals and work from verified copies. Default to read-only inspection and isolated execution.

- Distinguish direct evidence, tool output, interpretation, hypothesis, and unknowns.

- Use independent validation: reopen artifacts, compare hashes, cross-check tools, rerun from clean state, and retain failing cases.

- Prefer narrowly triggered, composable skills over one oversized skill. Put detailed format or platform knowledge in progressive references.

- Require explicit authorization for dynamic analysis, instrumentation, secrets handling, malware analysis, or modification of third-party systems.

- Produce editable, reproducible deliverables: commands, scripts, fixtures, parsers, reports, limitations, and rollback paths.

Catalog scope: 30 categories and 260 proposed skills.
