220 skills across 18 categories

Catalog Purpose

This catalog defines a broad set of reusable agent skills for accessibility and localization work. Each entry is written as a capability that can later be implemented, tested, composed with other skills, and governed as part of a larger agent system.

Coverage Principles

- Accessibility is treated as a complete user-journey property, not a one-time automated scan.

- Localization includes internationalization architecture, language quality, functional QA, typography, culture, release operations, and human review.

- Human disabled-user testing and human translation review remain essential even when automation is strong.

- Every skill should produce inspectable evidence, clear findings, actionable remediation, and repeatable verification when implemented.

- The catalog covers web, mobile, desktop, documents, media, kiosks, embedded devices, and emerging interfaces.

Implementation Note

This is a skill catalog only. It does not claim that the listed skills are already implemented. A future Skill Catalog builder can convert entries into individual skill specifications with inputs, outputs, dependencies, test fixtures, pass criteria, failure handling, and versioned documentation.

Appendix: Recommended Skill Specification Fields

When these catalog entries are converted into executable skills, use a consistent specification so they can be evaluated, repaired, reused, and combined safely.

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------
  Field                               Definition
  ----------------------------------- ---------------------------------------------------------------------------------------------------------------------------
  Purpose                             The exact user or system outcome the skill is responsible for.

  Triggers                            Requests, files, conditions, or workflow states that should activate the skill.

  Inputs                              Required and optional data, formats, versions, locales, platforms, and constraints.

  Outputs                             Artifacts, reports, structured findings, fixes, evidence, and status returned.

  Supported Standards                 Applicable WCAG criteria, platform guidance, document standards, or localization rules.

  Toolchain                           Approved scanners, assistive technologies, browsers, devices, parsers, and review environments.

  Execution Procedure                 Ordered steps with checkpoints and deterministic handoffs.

  Pass and Fail Criteria              Observable conditions that determine success, failure, severity, and release blocking.

  Human Review Points                 Decisions requiring disabled users, translators, linguists, subject experts, or legal owners.

  Edge Cases                          Dynamic states, unusual inputs, mixed scripts, offline use, slow networks, errors, and assistive-technology combinations.

  Evidence                            Screenshots, transcripts, logs, test cases, sample files, issue references, and verification results.

  Repair Strategy                     How to isolate root causes, preserve passing work, implement the smallest fix, and retest regressions.

  Privacy and Security                Rules for recordings, personal data, user-generated content, third parties, and secure retention.

  Versioning                          Skill version, standards baseline, dependencies, supported products, and deprecation policy.
