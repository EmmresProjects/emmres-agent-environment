A comprehensive catalog of reusable capability concepts for building agents that can divide work, operate concurrently, coordinate specialized workers, verify results, recover from failure, and deliver unified outcomes.

Catalog Guide

Each entry is a proposed reusable skill concept. The catalog describes purpose and scope only; it does not contain executable skill packages. Names can be used as starting points for future SKILL.md packages, worker roles, orchestration modules, or capability registry entries.

Category 1: Core Instance and Worker Orchestration

1. Skill Name: Instance Manager

Description: Creates, names, starts, pauses, resumes, clones, and retires independent work instances while tracking purpose, state, owner, dependencies, and resource limits.

2. Skill Name: Worker Factory

Description: Creates specialized workers from reusable role templates, gives each worker a bounded mandate, and verifies readiness before assignment.

3. Skill Name: Thought Processor

Description: Runs a defined reasoning lens such as decomposition, critique, synthesis, estimation, or constraint checking and returns structured conclusions rather than hidden chain-of-thought.

4. Skill Name: Multitasking Manager

Description: Splits a goal into parallel-safe workstreams, assigns workers, controls concurrency, resolves dependencies, and merges results into one coherent deliverable.

5. Skill Name: Worker Registry

Description: Maintains a live directory of workers, capabilities, tools, permissions, availability, current assignments, and performance history.

6. Skill Name: Role Blueprint Builder

Description: Defines worker roles with mission, inputs, outputs, allowed actions, quality gates, escalation rules, and completion criteria.

7. Skill Name: Instance Lifecycle Controller

Description: Applies consistent lifecycle states such as proposed, ready, running, blocked, reviewing, completed, failed, and archived.

8. Skill Name: Worker Pool Autoscaler

Description: Expands or contracts worker pools based on queue depth, task complexity, deadlines, cost budgets, and observed throughput.

9. Skill Name: Ephemeral Worker Launcher

Description: Creates short-lived workers for isolated tasks, captures their outputs and lessons, then safely disposes of their transient state.

10. Skill Name: Persistent Specialist Manager

Description: Maintains long-lived specialists with stable domain memory, operating procedures, benchmarks, and controlled updates.

11. Skill Name: Worker Capability Profiler

Description: Tests and records what each worker can reliably do, including limits, tool access, latency, quality, and preferred task types.

12. Skill Name: Assignment Dispatcher

Description: Routes each task to the best available worker using capability fit, urgency, workload, risk, context locality, and expected cost.

13. Skill Name: Worker Supervisor

Description: Monitors worker progress, detects drift or stalls, requests checkpoints, intervenes when thresholds are exceeded, and records outcomes.

14. Skill Name: Coordinator of Coordinators

Description: Organizes multiple team leads or sub-orchestrators so very large goals can be managed hierarchically without losing accountability.

15. Skill Name: Workcell Composer

Description: Builds temporary teams of complementary workers for a specific mission and defines their communication and handoff pattern.

16. Skill Name: Instance Isolation Guard

Description: Keeps worker contexts, files, secrets, and side effects separated unless an explicit, validated handoff authorizes sharing.

Category 3: Parallel Execution and Concurrency

3. Skill Name: Parallel Safety Analyzer

Description: Checks whether tasks can run together without conflicting edits, duplicated actions, inconsistent assumptions, or shared-resource races.

4. Skill Name: Speculative Branch Runner

Description: Runs reversible alternative approaches in parallel, compares observed results, and retains the strongest branch.

5. Skill Name: Map-Reduce Coordinator

Description: Distributes comparable units of work across workers, normalizes partial outputs, and reduces them into a verified aggregate.

6. Skill Name: Fan-Out Fan-In Manager

Description: Broadcasts a bounded assignment to many specialists and gathers their results through a defined merge and validation stage.

7. Skill Name: Race-to-Valid Solver

Description: Runs several independent solution attempts and selects the first result that passes all required checks, not merely the fastest answer.

8. Skill Name: Concurrent Edit Coordinator

Description: Allocates non-overlapping files, sections, records, or components and protects merge boundaries during simultaneous editing.

9. Skill Name: Parallel Research Controller

Description: Assigns distinct questions, source classes, or hypotheses to researchers and prevents redundant or circular evidence gathering.

10. Skill Name: Throughput Optimizer

Description: Balances batch size, worker count, task granularity, and review capacity to maximize useful completed work rather than raw activity.
