How to Use This Catalog

This catalog is a blueprint for a game-making agent or a coordinated family of specialist agents. It defines capabilities and expected outcomes. It does not implement the skills.

The version-intelligence skills are essential. No single static catalog can safely contain every old and future engine behavior, so an implementation should retrieve official version-specific documentation, lock dependencies, test the actual environment, and preserve compatibility notes.

Each implemented skill should produce editable source, explicit build instructions, tests that can fail, version and dependency data, and a runnable or verifiable result whenever the requested environment supports it.

Recommended Contract for Every Future Skill

  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Contract Area                       Expected Design
  ----------------------------------- ------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Inputs                              Game goal, genre, engine, exact version, language, target platform, assets, references, constraints, repository, build environment, and acceptance criteria.

  Outputs                             Editable project, source code, assets or schemas, tests, build instructions, runnable build when supported, dependency lock, version notes, and handoff.

  Controls                            Mechanics, platform, quality, performance budget, art and audio systems, networking, save behavior, difficulty, content scope, and compatibility targets.

  Checks                              Compilation, static analysis, tests, clean startup, gameplay path, saves, performance, platform behavior, accessibility, security, packaging, and clean-machine build.

  Recovery                            Capture the exact mismatch, isolate the earliest failing layer, preserve passing work, repair the smallest component, and rerun linked tests from clean state.

  Interoperability                    Document engine and editor version, SDKs, compiler, language standard, packages, file formats, coordinate systems, units, input, networking, and build tooling.
  ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
