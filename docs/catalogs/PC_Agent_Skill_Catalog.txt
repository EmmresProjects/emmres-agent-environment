PC AGENT SKILL CATALOG

Windows, Linux, and Cross-Platform Desktop Capabilities

Target host: Linux x86_64 agent environment with optional Windows, ARM64, GPU, virtualization, macOS, and network-enabled workers

Purpose

A comprehensive catalog of reusable agent skills for lawful PC inspection, preservation, compatibility repair, building, signing, debugging, testing, migration, recovery, deployment, packaging, security, performance, and documentation. The catalog describes capabilities to implement. It does not claim that every named tool is already installed.

Operating boundaries

- Preserve originals and record hashes before modification.

- Use real Windows, macOS, GPU, virtualization, network, or licensed workers when the task requires them.

- Do not bypass DRM, anti-cheat, purchases, accounts, activation, credentials, privacy controls, or access controls.

- Prefer read-only inspection, reversible changes, snapshots, and clean-state verification.

- Treat vendor licenses, redistribution terms, code-signing keys, personal data, and restricted tools as explicit dependencies.

Current baseline tools

OpenJDK 17; Python 3; Node.js and npm; Git; zip and unzip; file and strings; GNU readelf and objdump; llvm-readelf, llvm-readobj, and llvm-objdump.
