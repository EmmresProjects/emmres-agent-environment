IMAGE CREATION AND EDITING
SKILL CATALOG

Generation, Editing, GIFs, Animation Frames, Formats, Production, and Quality

A comprehensive catalog of reusable image capability concepts for creating, transforming, restoring, animating, organizing, validating, and delivering visual assets across realistic, fictional, artistic, technical, commercial, and educational uses.

29 categories | 290 skill concepts

Catalog Guide

Each entry is a proposed reusable skill concept. This catalog describes purpose and scope only. It does not contain executable skill packages or claim that every file format is supported by every image tool. Future builders should connect each skill to the image models, editors, encoders, storage systems, and review tools available in the target environment.

Recommended Fields for Future Skill Builds

- Trigger conditions and example requests

- Accepted inputs, references, masks, and image formats

- Output contract, dimensions, color mode, transparency, and naming

- Generation or editing workflow and preservation rules

- Safety, consent, rights, provenance, and disclosure controls

- Quality gates for composition, realism, continuity, text, and artifacts

- Batch behavior, resource limits, retries, and failure recovery

- Editable masters, derivatives, metadata, and handoff tests
