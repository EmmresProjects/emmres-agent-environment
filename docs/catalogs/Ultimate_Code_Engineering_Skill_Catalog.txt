ULTIMATE

Code Engineering
Skill Catalog

240 specialized skill concepts across 30 categories

A capability blueprint for building coding agents that produce functional, efficient, secure, readable, testable, maintainable, and production-ready code.

  --------------------------------------------------------------------------------------------------------------------------------------------------------------
  Scope: programming languages, scripts, machine-near code, queries, configuration, build files, shaders, and documentation-adjacent code.
  --------------------------------------------------------------------------------------------------------------------------------------------------------------
  Core behavior: understand first, make the smallest justified change, validate with tools, and preserve behavior unless the request explicitly changes it.

  Design stance: apply SOLID, KISS, DRY, YAGNI, cohesion, coupling, information hiding, least surprise, and related principles contextually, not mechanically.

  Delivery stance: finish with runnable, inspectable, documented, and recoverable results.
  --------------------------------------------------------------------------------------------------------------------------------------------------------------

How to Use This Catalog

Each entry is a distinct candidate skill. A future skill builder can combine closely related entries into one package or keep them separate for precise triggering and progressive disclosure. Names are written as capability labels; descriptions define the expected operating behavior and quality bar.

- Select by task and risk, not by prestige or model ranking.

- Use the narrowest specialist that fully fits the request, with the Universal Code Improvement Orchestrator coordinating cross-domain work.

- Require baselines before refactoring, evidence before optimization, and executable checks before completion.

- Treat principles as decision lenses. A principle may apply, conflict with another, or be intentionally declined with a stated reason.

- Keep human readability, maintainability, accessibility, security, performance, and recovery in the definition of correctness.

1. Core Code Understanding and Intent Recovery

Recover purpose, behavior, assumptions, and constraints before changing code.

1. Skill Name: Code Intent Archaeologist

  Description: Reconstructs what code is meant to do from implementation, tests, comments, commit clues, schemas, and call sites. Separates confirmed behavior from assumptions and produces an evidence-backed change map before edits.

2. Skill Name: Repository Cartographer

  Description: Maps modules, packages, entry points, dependency directions, build paths, generated files, and ownership boundaries. Highlights high-risk joins and the smallest safe area for a requested change.

3. Skill Name: Execution Flow Tracer

  Description: Follows control flow across functions, events, callbacks, coroutines, queues, services, and processes. Explains normal, boundary, failure, retry, cancellation, and shutdown paths in human-readable form.

4. Skill Name: Data Flow and State Tracker

  Description: Tracks data origin, validation, transformation, storage, caching, mutation, synchronization, and disposal. Detects hidden state, stale state, ownership confusion, and unsafe trust-boundary crossings.

5. Skill Name: Invariant and Contract Extractor

  Description: Identifies preconditions, postconditions, invariants, side effects, error contracts, timing guarantees, and compatibility promises. Converts implicit rules into enforceable assertions, types, schemas, and tests.

6. Skill Name: Unknown Codebase Onboarding Guide

  Description: Builds a focused learning path for unfamiliar repositories, languages, frameworks, and build systems. Prioritizes runnable entry points, representative workflows, debugging hooks, and high-value documentation.

7. Skill Name: Requirement-to-Code Traceability Analyst

  Description: Links requirements and acceptance criteria to modules, tests, configurations, deployment units, and observable outcomes. Flags uncovered requirements, orphan logic, and behavior that lacks a stated business reason.

8. Skill Name: Behavior Preservation Guardian

  Description: Establishes a baseline before refactoring using characterization tests, snapshots, traces, golden files, and interface contracts. Detects accidental semantic drift while allowing intentional changes to be reviewed explicitly.

2. Syntax, Parsing, Formatting, and Structural Repair

Repair malformed source and normalize it without changing intended behavior.

1. Skill Name: Universal Syntax Repairer

  Description: Detects and repairs parse errors, missing delimiters, invalid indentation, malformed declarations, misplaced tokens, and broken literals across programming, scripting, markup, query, configuration, and shader languages.

2. Skill Name: Indentation and Whitespace Normalizer

  Description: Corrects indentation-sensitive blocks, mixed tabs and spaces, line endings, trailing whitespace, and accidental formatting drift. Preserves language and repository style while minimizing diff noise.

3. Skill Name: Delimiter and Scope Balancer

  Description: Repairs unmatched parentheses, braces, brackets, tags, quotes, template markers, and preprocessing regions. Uses parser context to avoid superficial fixes that create a different scope or meaning.

4. Skill Name: Import and Namespace Resolver

  Description: Fixes missing, duplicate, circular, ambiguous, shadowed, or incorrectly ordered imports and namespaces. Distinguishes runtime, type-only, test-only, platform, and optional dependencies.

5. Skill Name: Type and Declaration Syntax Fixer

  Description: Repairs invalid type annotations, generics, traits, interfaces, ownership declarations, modifiers, visibility, and language-version syntax. Preserves API intent and compiler compatibility.

6. Skill Name: Configuration Syntax Medic

  Description: Repairs JSON, YAML, TOML, XML, INI, environment, manifest, CI, infrastructure, and build configuration syntax. Validates schemas, references, quoting, escaping, anchors, and platform-specific paths.

7. Skill Name: Query and Expression Syntax Fixer

  Description: Repairs SQL, GraphQL, regular expressions, XPath, shell expressions, template expressions, and embedded DSL fragments. Verifies escaping and host-language boundaries to prevent injection or silent misparsing.

8. Skill Name: Formatter and Linter Harmonizer

  Description: Selects and configures formatters and linters so automated rules agree instead of fighting each other. Produces stable, deterministic output and separates correctness rules from subjective style.

3. Readability, Naming, and Human Comprehension

Make code understandable to maintainers without inflating abstraction.

1. Skill Name: Human-Readable Code Rewriter

  Description: Reorganizes code around clear intent, direct control flow, meaningful names, and appropriately sized units. Removes cleverness and incidental complexity while protecting behavior and performance requirements.

2. Skill Name: Semantic Naming Specialist

  Description: Renames variables, functions, types, events, files, database objects, and APIs to reflect domain meaning and units. Avoids vague names, misleading abbreviations, accidental collisions, and context-free terminology.

3. Skill Name: Comment Quality Curator

  Description: Removes comments that merely restate syntax and creates comments for rationale, constraints, hazards, trade-offs, and non-obvious behavior. Keeps comments synchronized with the code and avoids invented explanations.

4. Skill Name: Complex Condition Explainer

  Description: Decomposes dense boolean logic, nested predicates, policy checks, and guard rules into named concepts. Preserves short-circuit behavior and makes precedence, null handling, and edge cases visible.

5. Skill Name: Control Flow Simplifier

  Description: Reduces deep nesting, duplicated branches, flag-driven logic, and scattered exits using guards, extraction, tables, or state models when appropriate. Rejects transformations that hide important sequencing.

6. Skill Name: Cognitive Complexity Reducer

  Description: Finds code that is difficult to mentally simulate and lowers cognitive load through cohesive functions, explicit state, local reasoning, and smaller dependency surfaces. Treats measured complexity as a signal, not an automatic verdict.

7. Skill Name: API Clarity Editor

  Description: Improves parameter names, return structures, defaults, overloads, errors, examples, and discoverability. Creates interfaces that guide callers toward correct use and make misuse difficult.

8. Skill Name: Code Explanation Generator

  Description: Produces layered explanations for students, maintainers, reviewers, operators, and domain experts. Includes purpose, inputs, outputs, flow, risks, examples, and extension points without exposing private reasoning.

4. Refactoring Principles and Design Discipline

Apply principles contextually rather than mechanically.

1. Skill Name: SOLID Applicability Reviewer

  Description: Evaluates single responsibility, open-closed design, substitutability, interface segregation, and dependency inversion at the correct scale. Recommends only changes that reduce real coupling or change cost.

2. Skill Name: KISS Simplicity Enforcer

  Description: Finds unnecessary indirection, speculative frameworks, excessive configurability, and clever constructs. Replaces them with the simplest design that still satisfies known constraints and extension needs.

3. Skill Name: DRY Duplication Analyst

  Description: Distinguishes harmful knowledge duplication from harmless or stabilizing repetition. Consolidates shared rules only when their reasons to change are truly the same.

4. Skill Name: YAGNI Scope Guardian

  Description: Removes or defers unused abstractions, options, hooks, layers, and features that are not justified by present requirements. Preserves low-cost extension seams where future change is credible and costly.

5. Skill Name: Separation of Concerns Architect

  Description: Separates domain rules, orchestration, persistence, transport, presentation, platform integration, and policy. Prevents boundaries from becoming ceremony by keeping interfaces proportional to system size.

6. Skill Name: Composition over Inheritance Refactorer

  Description: Replaces fragile inheritance hierarchies with composition, delegation, traits, or protocols when behavior varies independently. Retains inheritance where subtype semantics and shared lifecycle are genuine.

7. Skill Name: Law of Demeter Coupling Reducer

  Description: Detects train-wreck calls and knowledge of distant object structure. Introduces intention-revealing operations or focused adapters without creating gratuitous pass-through methods.

8. Skill Name: Principle Conflict Resolver

  Description: Handles collisions among simplicity, reuse, performance, testability, compatibility, security, and delivery speed. Records the chosen trade-off, rejected alternatives, and conditions that would justify revisiting it.

5. Code Smells and Technical Debt

Detect, prioritize, and repair maintainability risks.

1. Skill Name: Code Smell Triage Expert

  Description: Detects long methods, large classes, feature envy, shotgun surgery, primitive obsession, data clumps, divergent change, dead code, and speculative generality. Ranks findings by impact, confidence, reach, and repair risk.

2. Skill Name: Long Function Decomposer

  Description: Splits oversized procedures along cohesive responsibilities and stable seams. Preserves order, mutation, error behavior, and hot-path performance while improving local testability.

3. Skill Name: God Object Breaker

  Description: Finds objects or modules that own too many responsibilities, dependencies, or lifecycle decisions. Extracts cohesive capabilities with explicit ownership and controlled migration steps.

4. Skill Name: Primitive Obsession Refactorer

  Description: Replaces ambiguous strings, numbers, flags, arrays, and dictionaries with value objects, enums, records, validated types, and units where this prevents defects. Avoids wrapper types that add no semantic value.

5. Skill Name: Feature Envy and Ownership Corrector

  Description: Moves behavior toward the data and invariants it understands best. Evaluates transaction boundaries, encapsulation, and performance before relocating code.

6. Skill Name: Dead Code and Reachability Cleaner

  Description: Identifies unreachable branches, unused symbols, obsolete flags, retired endpoints, abandoned migrations, and unreferenced assets. Requires evidence from static analysis, runtime usage, and release constraints before deletion.

7. Skill Name: Magic Value Eliminator

  Description: Replaces unexplained constants, sentinel values, bit masks, status strings, timeouts, and units with named domain concepts or configuration. Keeps values local when global abstraction would reduce clarity.

8. Skill Name: Technical Debt Portfolio Manager

  Description: Groups debt by root cause, affected capability, risk, maintenance cost, and dependency order. Produces incremental remediation batches with measurable exit criteria instead of an unbounded rewrite.

6. Architecture and Modular Design

Shape systems for change, scale, and clear ownership.

1. Skill Name: Architecture Fitness Reviewer

  Description: Evaluates whether the current architecture fits traffic, team size, release cadence, compliance, latency, reliability, and product volatility. Rejects fashionable patterns that do not solve the system’s actual pressures.

2. Skill Name: Module Boundary Designer

  Description: Defines cohesive modules with explicit APIs, dependency rules, ownership, and change reasons. Identifies cycles, leakage, shared-kernel risk, and unstable boundaries.

3. Skill Name: Layered Architecture Refactorer

  Description: Clarifies presentation, application, domain, and infrastructure responsibilities where layering is useful. Prevents circular layers and bypass paths while allowing performance-sensitive exceptions to be explicit.

4. Skill Name: Hexagonal and Clean Architecture Adapter

  Description: Separates core policy from external frameworks through ports and adapters. Applies the pattern selectively so small systems do not accumulate unnecessary interfaces and mapping layers.

5. Skill Name: Event-Driven Architecture Specialist

  Description: Designs events, commands, handlers, consumers, ordering, deduplication, retries, schemas, and observability. Distinguishes domain events from integration events and avoids event chains that hide control flow.

6. Skill Name: Monolith Modularization Planner

  Description: Improves a monolith through internal boundaries, package rules, database ownership, and independent test seams. Creates extraction readiness without forcing premature microservices.

7. Skill Name: Microservice Boundary and Merge Analyst

  Description: Uses domain cohesion, data ownership, operational independence, traffic patterns, and team ownership to split or recombine services. Detects distributed monoliths and chatty service boundaries.

8. Skill Name: Plugin and Extension Architecture Designer

  Description: Creates stable extension points, lifecycle contracts, capability negotiation, isolation, versioning, and failure containment. Protects the host from unsafe or incompatible plugins.

7. Algorithms, Data Structures, and Complexity

Choose efficient structures and prove meaningful improvements.

1. Skill Name: Algorithm Selection Advisor

  Description: Matches algorithms to input size, distribution, update frequency, accuracy, memory, latency, and determinism requirements. Explains complexity and operational trade-offs with concrete thresholds.

2. Skill Name: Time Complexity Optimizer

  Description: Finds accidental quadratic work, repeated scans, pathological recursion, expensive sorting, and redundant computation. Validates improvements with representative benchmarks rather than asymptotic claims alone.

3. Skill Name: Space Complexity Optimizer

  Description: Reduces unnecessary copies, oversized buffers, retained graphs, cache growth, and intermediate materialization. Balances memory reduction against CPU, I/O, readability, and fragmentation.

4. Skill Name: Data Structure Refactorer

  Description: Replaces unsuitable lists, maps, sets, trees, graphs, heaps, queues, bitsets, indexes, and probabilistic structures based on access patterns. Documents ordering, uniqueness, stability, and concurrency semantics.

5. Skill Name: Dynamic Programming and Memoization Specialist

  Description: Recognizes overlapping subproblems and designs tables, recurrence relations, cache keys, eviction, and reconstruction logic. Avoids memoization when state space, invalidation, or memory cost makes it harmful.

6. Skill Name: Graph and Pathfinding Engineer

  Description: Designs traversal, shortest-path, connectivity, scheduling, dependency, spatial, and network algorithms. Handles negative edges, cycles, heuristics, disconnected components, and large sparse graphs.

7. Skill Name: Numerical Stability Reviewer

  Description: Detects floating-point cancellation, overflow, underflow, precision loss, unstable recurrences, and unit errors. Selects stable formulations, tolerances, data types, and validation datasets.

8. Skill Name: Approximation and Heuristic Designer

  Description: Creates bounded approximations, streaming algorithms, sketches, sampling methods, and heuristics when exact computation is too expensive. States expected error, worst cases, and fallback behavior.

8. Performance, Profiling, and Resource Efficiency

Optimize observed bottlenecks while preserving correctness.

1. Skill Name: Evidence-Driven Performance Profiler

  Description: Builds reproducible profiles for CPU, memory, I/O, network, database, GPU, startup, and tail latency. Separates warm-up, caching, instrumentation overhead, and synthetic-test artifacts.

2. Skill Name: Hot Path Optimizer

  Description: Optimizes the small set of functions that dominate runtime using data layout, batching, vectorization, reduced allocation, and lower call overhead. Protects readability with benchmarks and targeted comments.

3. Skill Name: Allocation and Garbage Collection Reducer

  Description: Finds temporary objects, boxing, churn, large-object pressure, pauses, and retention. Applies pooling, reuse, arenas, stack allocation, or ownership changes only with lifecycle safety.

4. Skill Name: Cache Strategy Engineer

  Description: Designs local, distributed, HTTP, database, compiled, and asset caches with keys, invalidation, TTLs, capacity, stampede control, and observability. Treats stale data and cache poisoning as first-class failures.

5. Skill Name: I/O and Batching Optimizer

  Description: Reduces round trips, tiny reads and writes, synchronous waits, and inefficient serialization through buffering, batching, compression, streaming, and concurrency. Respects backpressure and memory bounds.

6. Skill Name: Startup and Build Time Optimizer

  Description: Profiles initialization, dependency loading, compilation, linking, asset processing, and test discovery. Uses lazy loading, incremental work, caching, and dependency trimming without hiding required failures.

7. Skill Name: Tail Latency Reducer

  Description: Targets p95, p99, and worst-case latency through queue control, timeout budgets, hedging where safe, workload isolation, and dependency analysis. Avoids improving averages while rare requests remain unusable.

8. Skill Name: Performance Regression Gate Designer

  Description: Creates stable microbenchmarks, end-to-end tests, budgets, baselines, variance handling, and CI thresholds. Detects meaningful regressions without producing noisy, ignored alerts.

9. Memory, Ownership, and Low-Level Systems

Make machine-near code safe, predictable, and efficient.

1. Skill Name: Memory Safety Auditor

  Description: Finds out-of-bounds access, use-after-free, double free, leaks, uninitialized reads, aliasing violations, and invalid lifetimes. Uses language ownership tools, sanitizers, fuzzing, and targeted proofs.

2. Skill Name: Ownership and Lifetime Refactorer

  Description: Clarifies who creates, borrows, transfers, mutates, and destroys resources. Applies RAII, linear ownership, smart pointers, regions, or explicit cleanup according to language semantics.

3. Skill Name: Pointer and Unsafe Code Reviewer

  Description: Audits pointer arithmetic, FFI, casts, packed structures, volatile access, and unsafe blocks. Narrows unsafe regions and documents invariants that callers must uphold.

4. Skill Name: Binary Layout and Endianness Specialist

  Description: Validates alignment, padding, byte order, bit fields, serialization, ABI assumptions, and cross-platform representation. Provides golden vectors and round-trip tests.

5. Skill Name: Assembly and Machine Code Analyst

  Description: Reads assembly, disassembly, intermediate representation, opcodes, calling conventions, register use, and compiler output. Connects machine behavior back to source-level performance and correctness.

6. Skill Name: SIMD and Vectorization Engineer

  Description: Applies vector instructions, data-oriented layouts, alignment, masking, and fallback paths. Verifies numerical equivalence, CPU feature detection, and gains on realistic hardware.

7. Skill Name: Embedded Resource Budgeter

  Description: Optimizes constrained firmware for flash, RAM, stack, power, timing, and peripheral limits. Accounts for interrupts, watchdogs, boot behavior, and field-update safety.

8. Skill Name: Real-Time Determinism Reviewer

  Description: Finds unbounded loops, blocking calls, dynamic allocation, priority inversion, jitter, and nondeterministic dependencies. Establishes worst-case timing evidence and safe degradation paths.

10. Concurrency, Parallelism, and Distributed Coordination

Prevent races and make coordination behavior explicit.

1. Skill Name: Concurrency Correctness Auditor

  Description: Finds data races, deadlocks, livelocks, starvation, lost wakeups, atomicity gaps, and unsafe publication. Models interleavings and verifies synchronization assumptions.

2. Skill Name: Locking Strategy Refactorer

  Description: Selects lock granularity, ordering, read-write locks, striped locks, or lock-free techniques based on contention and invariants. Documents lock ownership and prevents hidden blocking.

3. Skill Name: Async and Coroutine Specialist

  Description: Repairs async control flow, cancellation, timeout propagation, structured concurrency, exception handling, and resource cleanup. Prevents fire-and-forget leaks and sync-over-async deadlocks.

4. Skill Name: Parallel Workload Partitioner

  Description: Decomposes CPU, GPU, and batch workloads by data, tasks, stages, or actors. Balances work while controlling scheduling overhead, communication, and false sharing.

5. Skill Name: Backpressure and Queue Designer

  Description: Defines queue capacity, admission control, overflow policy, batching, retry, and producer feedback. Prevents unlimited buffering from converting transient pressure into system failure.

6. Skill Name: Distributed Consistency Analyst

  Description: Clarifies consistency, availability, ordering, quorum, replication, conflict, and partition requirements. Selects strong, causal, eventual, or application-level consistency deliberately.

7. Skill Name: Idempotency and Deduplication Engineer

  Description: Designs stable request keys, replay behavior, deduplication windows, transactional boundaries, and response caching. Handles partial success and duplicate delivery across retries.

8. Skill Name: Distributed Transaction and Saga Designer

  Description: Chooses local transactions, outbox patterns, sagas, compensation, and reconciliation for multi-system workflows. Makes irreversible actions and human-repair paths explicit.

11. Testing Strategy and Verification

Build confidence with layered, failure-capable tests.

1. Skill Name: Test Pyramid and Portfolio Architect

  Description: Balances unit, component, contract, integration, end-to-end, exploratory, performance, and production checks. Optimizes for defect detection, feedback speed, confidence, and maintenance cost.

2. Skill Name: Unit Test Quality Improver

  Description: Creates focused tests around observable behavior, invariants, boundaries, and errors. Reduces brittle implementation coupling, excessive mocks, and assertion noise.

3. Skill Name: Characterization Test Builder

  Description: Captures legacy behavior before risky changes using black-box tests, golden files, snapshots, traces, and differential runs. Labels suspicious behavior so preservation is intentional, not accidental.

4. Skill Name: Property-Based Testing Designer

  Description: Defines generators, properties, shrinking, state machines, and invariants for broad input exploration. Targets parsers, serializers, algorithms, protocols, and transformation pipelines.

5. Skill Name: Mutation Testing Specialist

  Description: Uses deliberate code mutations to reveal weak assertions and untested decisions. Prioritizes surviving mutants by business risk and filters equivalent or irrelevant mutations.

6. Skill Name: Fuzz Testing Engineer

  Description: Builds structured and coverage-guided fuzzers, corpora, dictionaries, sanitizers, timeouts, and crash minimization. Converts every confirmed failure into a durable regression test.

7. Skill Name: Test Data and Fixture Curator

  Description: Creates small, meaningful fixtures covering normal, missing, malformed, repeated, extreme, localized, and adversarial inputs. Prevents hidden coupling, privacy leakage, and nondeterministic data setup.

8. Skill Name: Flaky Test Eliminator

  Description: Diagnoses timing, ordering, shared state, external dependency, clock, randomness, resource, and environment causes. Repairs root causes and adds determinism rather than relying on retries alone.

12. Debugging, Failure Analysis, and Repair

Find the earliest bad state and repair the smallest cause.

1. Skill Name: Systematic Debugging Orchestrator

  Description: Turns symptoms into reproducible cases, competing hypotheses, discriminating probes, and verified repairs. Preserves passing behavior and avoids changing multiple causal factors at once.

2. Skill Name: Stack Trace and Crash Analyst

  Description: Interprets exceptions, core dumps, crash logs, native frames, minidumps, and symbol data. Correlates the failure with source, threads, inputs, builds, and environment.

3. Skill Name: Heisenbug and Timing Failure Hunter

  Description: Investigates failures altered by logging, debugging, optimization, load, or scheduling. Uses low-intrusion tracing, deterministic replay, stress schedules, and statistical reproduction.

4. Skill Name: Memory Leak and Retention Investigator

  Description: Finds leaked allocations, reference cycles, listener leaks, cache retention, handle leaks, and unclosed resources. Compares heap snapshots and ownership paths over time.

5. Skill Name: Production Incident Code Investigator

  Description: Connects telemetry, deploys, feature flags, traffic, logs, traces, metrics, and code changes to determine blast radius and earliest bad state. Produces safe mitigation and durable repair paths.

6. Skill Name: Differential Debugging Specialist

  Description: Compares passing and failing versions, environments, requests, configurations, or platforms to isolate relevant differences. Uses bisection and controlled substitution to reduce search space.

7. Skill Name: Root Cause and Five-Whys Analyst

  Description: Builds a causal chain that includes technical, process, detection, and recovery factors. Avoids stopping at individual error or vague labels such as human mistake.

8. Skill Name: Regression Repair Verifier

  Description: Reproduces the original failure, confirms the fix, tests adjacent cases, and reruns affected integration paths from clean state. Rejects fixes that only suppress symptoms.

13. Static Analysis, Types, and Formal Assurance

Use machine-checkable evidence to prevent defects.

1. Skill Name: Static Analysis Rule Curator

  Description: Configures analyzers for defects that matter to the codebase, language, and threat model. Tunes severity, suppressions, baselines, and rollout so findings remain actionable.

2. Skill Name: Type Safety Enhancer

  Description: Replaces ambiguous, nullable, dynamically shaped, or weakly constrained values with precise types. Uses unions, generics, branded types, protocols, refinements, and exhaustive matching where they reduce runtime uncertainty.

3. Skill Name: Nullability and Optionality Refactorer

  Description: Makes absence explicit and controls defaults, sentinels, nullable fields, and partial objects. Prevents hidden null propagation and distinguishes missing, unknown, empty, and invalid states.

4. Skill Name: Schema and Contract Validator

  Description: Defines and enforces schemas for APIs, messages, files, configuration, database records, and events. Handles compatibility, defaults, unknown fields, and partial rollout.

5. Skill Name: Abstract Interpretation Specialist

  Description: Applies range, taint, alias, reachability, and state analysis to find defects without execution. Balances precision and cost while explaining false positives and analysis limits.

6. Skill Name: Formal Specification Writer

  Description: Expresses critical behavior as invariants, state machines, temporal properties, preconditions, and postconditions. Keeps specifications linked to executable tests or model checks.

7. Skill Name: Model Checking and State-Space Analyst

  Description: Explores concurrent protocols, workflows, and distributed algorithms across possible states. Uses abstraction and bounded exploration to find counterexamples and unreachable assumptions.

8. Skill Name: Proof-Oriented Critical Code Reviewer

  Description: Applies proof sketches, exhaustive reasoning, and mechanically checkable claims to safety-critical algorithms and transformations. Clearly separates proven properties from tested or assumed ones.

14. Security Engineering and Secure Refactoring

Reduce vulnerabilities while preserving intended use.

1. Skill Name: Secure Code Review Specialist

  Description: Reviews authentication, authorization, input handling, secrets, cryptography, sessions, files, network calls, and unsafe operations. Prioritizes exploitable paths and provides minimally disruptive remediation.

2. Skill Name: Injection Defense Engineer

  Description: Prevents SQL, command, template, LDAP, XPath, header, log, and code injection through parameterization, safe APIs, validation, escaping, and privilege reduction. Tests context-specific bypasses.

3. Skill Name: Authentication and Session Hardener

  Description: Improves password, token, key, cookie, session, MFA, recovery, logout, rotation, and device flows. Detects fixation, replay, leakage, and inconsistent invalidation.

4. Skill Name: Authorization and Access Control Auditor

  Description: Verifies object, function, field, tenant, role, scope, and policy checks at trusted boundaries. Finds confused deputy, insecure direct object reference, and privilege escalation paths.

5. Skill Name: Secrets and Credential Hygiene Specialist

  Description: Finds embedded secrets, unsafe logs, broad credentials, insecure storage, weak rotation, and accidental artifact leakage. Migrates to scoped secret stores and revocation-ready workflows.

6. Skill Name: Dependency Vulnerability Remediator

  Description: Triages vulnerable packages by reachability, exploitability, fix availability, and regression risk. Upgrades, patches, replaces, or isolates dependencies with compatibility tests.

7. Skill Name: Cryptography Usage Reviewer

  Description: Detects obsolete algorithms, nonce reuse, weak randomness, unsafe modes, homemade protocols, key misuse, and insecure comparisons. Prefers vetted libraries and documented threat assumptions.

8. Skill Name: Threat Modeling and Abuse Case Designer

  Description: Maps assets, actors, trust boundaries, entry points, threats, misuse, mitigations, and residual risk. Converts the model into code controls, tests, logging, and review checkpoints.

15. API, Protocol, and Integration Engineering

Create durable interfaces across components and organizations.

1. Skill Name: API Contract Designer

  Description: Designs resources, operations, schemas, errors, pagination, filtering, idempotency, and discoverability. Aligns protocol shape with domain behavior instead of exposing storage internals.

2. Skill Name: Backward Compatibility Guardian

3. Skill Name: REST API Quality Improver

4. Skill Name: GraphQL Schema Optimizer

  Description: Improves schema cohesion, nullability, resolver batching, pagination, authorization, error handling, and query cost controls. Detects N+1 access and accidental data exposure.

5. Skill Name: RPC and gRPC Contract Specialist

  Description: Designs service methods, protobuf messages, deadlines, streaming, retries, status mapping, compatibility, and load behavior. Prevents chatty interfaces and ambiguous partial success.

6. Skill Name: Webhook Reliability Engineer

  Description: Creates signature verification, replay protection, retries, idempotency, ordering, rate limits, delivery logs, and consumer recovery. Handles duplicates and prolonged receiver outages.

7. Skill Name: Protocol Parser and Serializer Engineer

  Description: Builds strict, bounded, streaming, version-aware parsers and serializers for text or binary protocols. Defends against malformed lengths, recursion, ambiguity, and resource exhaustion.

8. Skill Name: Integration Adapter Refactorer

  Description: Isolates vendor SDKs, external schemas, and platform quirks behind focused adapters. Preserves domain language and makes provider replacement, testing, and failure handling practical.

16. Data, Database, and Persistence Code

Improve correctness, performance, and evolvability of stored data.

1. Skill Name: Database Access Pattern Reviewer

  Description: Examines queries, transactions, indexes, locking, connection use, batching, and object mapping. Finds N+1 queries, full scans, chatty access, and consistency gaps.

2. Skill Name: SQL Query Optimizer
