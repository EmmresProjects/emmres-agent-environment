Purpose

This catalog gives a future skill builder a wide set of automation capabilities. It covers scripts, bots, schedulers, desktop actions, files, documents, browser work, data mining, APIs, cloud systems, development, business work, media, monitoring, safety, testing, and clean handoff.

Core design rules

- Automate only authorized actions and approved data.

- Use dry runs, clear logs, bounded retries, and safe failure behavior.

- Keep secrets out of code, files, prompts, and logs.

- Require review before destructive, financial, public, or high-impact actions.

- Make every tool installable, testable, repairable, and easy to stop.

- Preserve source inputs and provide rollback or recovery when changes are made.

Suggested Catalog Use

A future agent can use this catalog as a router. A request such as “process new invoices every night” may combine Workflow Automation Architect, Folder Watch Bot, OCR and Scanned Document Bot, Invoice Processing Bot, Data Validation Gate, Approval Workflow Builder, Audit Log Builder, Universal Task Scheduler, and Automation Test Harness.

Recommended Skill Bundle Pattern

1.  Plan: define the trigger, input, result, permission, risk, owner, and acceptance checks.

2.  Build: create the smallest complete automation and make the normal path work.

3.  Protect: add validation, least privilege, dry run, secrets handling, and confirmation gates.

4.  Test: cover normal, boundary, repeated, failure, recovery, and joined behavior.

5.  Operate: add scheduling, logs, metrics, alerts, ownership, and stop controls.

6.  Handoff: include source, runnable output, configuration, readme, tests, and repair steps.

Build Note

When these ideas become real Skills, each Skill should define exact triggers, accepted inputs, outputs, platforms, dependencies, permissions, safety limits, checks, recovery steps, and handoff format. Use separate scripts, references, templates, and assets so the main Skill instructions remain short.
