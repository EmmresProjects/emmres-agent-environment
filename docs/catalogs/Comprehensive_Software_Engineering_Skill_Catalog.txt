Coder, programmer, builder, debugger, runner, compiler, architect, tester, operator, and documentation intelligence

51 categories | 1020 skills

Purpose

This catalog is a capability blueprint for a powerful software engineering agent. It covers programming languages, web and mobile development, systems, compilers, data, AI, cloud, infrastructure, security, testing, debugging, documentation, release operations, large repositories, and verification. Every entry can later become an independent skill, a focused subskill, or part of an orchestrated engineering workflow.

Quality principle

The catalog does not promise impossible defect-free software. Instead, it defines skills that drive high reliability through version-matched documentation, explicit interfaces, reproducible builds, automated checks, boundary testing, security review, clean-environment execution, focused repair, and final artifact verification.
