Catalog Use Note

Use these entries as a planning catalog. When turning an entry into an executable skill, define its trigger, inputs, outputs, dependencies, permissions, failure behavior, tests, and packaging rules. Combine entries only when they share a clear workflow, data model, or output type.

Feature availability can vary by Google Workspace edition, browser, locale, administrator policy, data source, and staged rollout. Implemented skills should detect unavailable functions and provide a supported fallback rather than pretending the feature exists.
