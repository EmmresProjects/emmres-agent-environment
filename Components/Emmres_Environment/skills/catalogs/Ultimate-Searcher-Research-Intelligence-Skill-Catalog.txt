A comprehensive catalog of composable agent skills for broad discovery, deep searching, website traversal, evidence gathering, source verification, structured extraction, synthesis, monitoring, and reproducible research.

  -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Catalog purpose. This document proposes focused skills for later implementation. It does not contain implemented skills or promise literal exhaustive coverage of the internet. Strong implementations should maximize relevant coverage through bounded, lawful, privacy-aware methods and should report unresolved gaps honestly.
  -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

  -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Search and Research Principles

- Define the question, scope, freshness, audience, evidence standard, and stop conditions before searching.

- Use multiple query families, source classes, languages, dates, and viewpoints when the topic requires broad coverage.

- Prioritize primary and authoritative sources, then use secondary and community sources for context, discovery, and lived experience.

- Open and verify underlying sources. Search snippets, reposts, and summaries are leads, not final evidence.

- Track provenance, contradictions, missing evidence, inaccessible sources, and remaining uncertainty.

- Stop when declared coverage is met or additional searching has low expected value, then deliver a clear, source-grounded synthesis.

Catalog scope: 35 categories and 350 proposed skills.

Category 1: Search Strategy and Query Architecture

1. Skill Name: Research Objective Interpreter

  Description: Transforms a prompt into answerable questions, evidence needs, freshness rules, scope boundaries, and completion criteria.

2. Skill Name: Query Decomposition Architect

  Description: Breaks broad topics into nonredundant searches for entities, dates, locations, methods, controversies, and source types.

3. Skill Name: Query Expansion Specialist

  Description: Generates synonyms, acronyms, alternate spellings, translations, technical terms, historical names, and related concepts.

4. Skill Name: Search Intent Classifier

  Description: Distinguishes factual, navigational, comparative, investigative, exploratory, transactional, and source-seeking intent.

5. Skill Name: Boolean Query Engineer

  Description: Builds precise AND, OR, NOT, phrase, wildcard, proximity, and field-limited queries for supported search systems.

6. Skill Name: Advanced Search Operator Specialist

  Description: Uses site, filetype, intitle, inurl, date, language, region, author, and domain filters where supported.

7. Skill Name: Search Funnel Designer

  Description: Moves from broad discovery to focused verification while preserving useful leads and avoiding premature narrowing.

8. Skill Name: Negative Keyword Designer

  Description: Removes recurring noise, ambiguous meanings, duplicate markets, unrelated products, and low-value result types.

9. Skill Name: Query Portfolio Manager

  Description: Maintains diverse query families so one wording, language, platform, or ranking system does not control the evidence.

10. Skill Name: Search Stop-Condition Designer

  Description: Defines bounded saturation, unresolved contradiction, freshness, coverage, and diminishing-return conditions.
