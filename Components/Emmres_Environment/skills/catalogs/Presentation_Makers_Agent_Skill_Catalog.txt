Catalog Use Note

When implementing a catalog entry, define trigger, inputs, outputs, platform, account or plan requirements, dependencies, permissions, fallbacks, tests, and packaging rules. Combine skills only when they share a clear workflow, asset model, or output type.

Cloud presentation features vary by plan, region, browser, administrator policy, AI credits, and staged rollout. Implemented skills should detect missing capabilities and choose an honest fallback.
