Purpose

This catalog gives a strong builder a wide set of reusable skill ideas for sprite production. The set covers creation, animation, editing, packing, game integration, quality checks, automation, handoff, and safe team use. The entries are written as separate capabilities so an agent can route work to the right tool instead of forcing one large skill to do every task.

Catalog design rules

- Use one clear responsibility per skill.

- Keep source files editable and final files ready to use.

- Support batch work, repair, checking, and clean handoff.

- Preserve frame order, pivots, timing, transparency, palette, camera, and style.

- Choose output rules based on the target engine, runtime, platform, or media use.

Suggested Catalog Use

A future agent can treat this catalog as a routing map. A single request may use several focused skills in order. For example, a new eight-direction game character may use Character Sprite Architect, Directional Sprite Set Maker, Movement Cycle Animator, Anchor and Pivot Manager, Sprite Sheet Composer, Atlas Metadata Writer, Engine Import Preparer, and Sprite Sheet Validator.

Recommended Skill Bundle Pattern

1.  Planning: brief, style bible, action matrix, camera, and export target.

2.  Creation: source sprite, views, parts, animation, effects, and variants.

3.  Assembly: frame cleanup, sheet layout, atlas packing, metadata, and previews.

4.  Validation: visual review, loop checks, anchors, palette, engine import, and regression checks.

5.  Handoff: editable masters, final exports, readme, license notes, and version record.

Build Note

When these ideas are turned into real Skills, each Skill should define its trigger, accepted inputs, exact outputs, tool needs, failure states, quality checks, and handoff format. Large references, templates, scripts, and assets should live in separate resource folders so the main instructions stay short and easy to load.
