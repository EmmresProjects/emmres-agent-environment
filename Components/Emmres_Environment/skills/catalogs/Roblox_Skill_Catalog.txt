How to Use This Catalog

Each entry is a candidate agent skill, not an implemented tool. A future skill builder can turn an entry into instructions, tools, schemas, tests, examples, safeguards, and acceptance checks.

Use one primary skill for a focused task, or compose several skills for an end-to-end workflow. For example, Layered Clothing Modeler can pair with Cage Debugging Specialist, Avatar Import Validator, Marketplace Compliance Preflight, and Asset Thumbnail Director.

The catalog deliberately separates creation, validation, optimization, safety, publishing, and operations. This makes execution easier to test and repair than a single oversized Roblox skill.

Platform features change. Before implementation, verify APIs, limits, policies, eligibility, and release status against current Roblox Creator documentation.

Recommended Skill Specification

- Purpose and trigger conditions

- Required inputs and supported asset types

- Tools, Roblox services, and external dependencies

- Step-by-step execution workflow

- Client-server trust and safety rules

- Normal, boundary, failure, and recovery tests

- Editable outputs and validation report

- Version, deprecation, and platform-change notes

Implementation Quality Standard

Requirement coverage

The implemented skill must map every promised capability to an observable output and a check that can fail.

Roblox correctness

Use current Roblox classes, services, security boundaries, asset requirements, platform rules, and supported cloud interfaces.

Safe authority

Treat clients as untrusted. Validate identity, ownership, timing, state, values, and permissions on the server.

Robust execution

Handle missing assets, latency, service failure, duplicate calls, disconnects, shutdown, retries, rollback, and cleanup.

Performance

Set measurable budgets for frame time, memory, network traffic, instances, physics, asset size, and load time when relevant.

Cross-device quality

Test phone, tablet, desktop, console, and other supported input or display modes relevant to the experience.

Verification

Include unit, integration, multiplayer, boundary, regression, visual, and release-path checks appropriate to the skill.

Handoff

Return editable artifacts, clear file locations, configuration, dependencies, limitations, and the next safe action.
