How to Use This Catalog

This catalog is a blueprint for a powerful web-making agent or a coordinated family of specialist agents. It defines capabilities and expected outcomes. It does not implement the skills.

The version-intelligence skills are essential. A static document cannot safely contain every past and future framework, browser, cloud, runtime, and hosting behavior, so implementations should retrieve official version-specific documentation, lock dependencies, test the actual environment, and preserve compatibility notes.

Every implemented skill should produce editable source, explicit local and hosted run instructions, tests that can fail, accessibility and security checks, dependency and environment data, and a deployable or verifiable result whenever access permits.
