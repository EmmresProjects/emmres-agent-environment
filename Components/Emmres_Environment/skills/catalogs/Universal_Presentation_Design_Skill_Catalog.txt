How to Use This Catalog

Each entry is a candidate agent skill, not an implemented skill. A future skill specification can add triggers, inputs, outputs, tools, constraints, tests, examples, and recovery behavior.

The catalog is intentionally broad. It covers strategy, content, layout, typography, color, imagery, data visualization, motion, multimedia, interactivity, platform operation, automation, accessibility, localization, governance, quality assurance, and specialized presentation scenarios.

For implementation, combine only closely related capabilities. Keep platform-specific execution separate when file formats, APIs, permissions, or rendering behavior differ.

Catalog Design Principles

- Editable outputs before flattened exports

- Explicit visual and functional quality checks

- Cross-platform fidelity with platform-native fallbacks

- Brand, accessibility, privacy, and licensing awareness

- Clear separation of planning, creation, review, repair, and delivery

- Reusable templates and structured handoffs

Recommended Skill Specification Fields

Skill identity: Name, purpose, category, supported platforms, version, and owner.

Triggers: Clear user intents and conditions that require this skill, plus non-trigger examples.

Inputs: Required files, source content, brand assets, data schemas, audience, format, and constraints.

Outputs: Editable source, export formats, dimensions, naming conventions, and handoff package.

Tool contract: Allowed applications, APIs, libraries, permissions, and fallback paths.

Execution workflow: Inspect, plan, create, render, review, repair, re-render, and deliver.

Quality checks: Layout, clipping, alignment, typography, contrast, reading order, links, media, file integrity, and cross-platform fidelity.

Failure handling: Missing fonts, broken links, unavailable assets, unsupported effects, corrupt files, permission errors, and export differences.

Examples and tests: Normal, boundary, repeated-use, accessibility, localization, and recovery cases.

Safety and compliance: Privacy, copyright, trademarks, licenses, sensitive data, and organizational policy.
