POWERPOINT AGENT SKILL CATALOG

A comprehensive capability blueprint for agents that create, edit, audit, repair, automate, and deliver Microsoft PowerPoint work

Edition 1.0 | 50 categories | 350 proposed skills

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Purpose: This catalog proposes distinct reusable skills, not already-built skill packages. It uses the supplied PowerPoint feature guide as the baseline and expands it into execution, auditing, repair, automation, domain, accessibility, compatibility, and delivery scenarios. Skills should preserve editability, use feature-aware routing, test the final artifact, and select fallbacks when a feature is unavailable.
  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

How to Use This Catalog

- Treat each entry as a candidate modular skill with its own trigger description, workflow, references, scripts, assets, tests, and failure handling.

- Use narrow skills for dependable repeated operations and an orchestration skill to route multi-step requests across them.

- Implement skills progressively: metadata and SKILL.md first, then references, deterministic scripts, templates/assets, test fixtures, and packaging.

- Separate authoring, auditing, repair, and automation because they have different triggers, risks, and validation requirements.

- Validate created PowerPoint files by reopening them, checking slide structure, rendering slides, testing media and hyperlinks, and checking export outputs.

Standard Skill Contract

Inputs: User goal, audience, source files, template or brand rules, required PowerPoint edition, target platform, output formats, and constraints.

Outputs: Editable PPTX or related artifacts, requested exports, concise issue report when auditing, and a clean handoff package.

Execution: Inspect first, choose the smallest capable feature/tool path, preserve passing work, make reversible changes, and avoid destructive flattening.

Validation: Check requirement coverage, slide count, object bounds, visual rendering, fonts, links, media, notes, reading order, accessibility, compatibility, and requested exports.

Fallbacks: When a feature is unavailable, use a documented compatible alternative and state the material limitation in the handoff.

Security: Do not enable unknown macros or external content; respect Protected View, permissions, privacy, and organizational policy.

1. Intake, Intent, and Requirements

  Coverage focus: Intake, Intent, and Requirements. The skills below are intentionally separated by execution role so an agent can route work precisely and validate it appropriately.

1. Skill Name: Intake, Intent, and Requirements Architect

Description: Designs a complete presentation intake and requirements plan from goals, audience, constraints, and source material; selects suitable PowerPoint features, defines acceptance checks, and preserves an editable structure.

Use when: the user needs planning, requirements translation, a design system, or a safe execution route before editing.

Core checks: Preserve editability; verify object bounds and reading order; inspect rendered slides; test links, media, and animations when relevant; confirm target-platform behavior; and save to a new output unless instructed otherwise.

2. Skill Name: Intake, Intent, and Requirements Builder

Description: Creates and edits presentation intake and requirements deliverables using brief analysis, constraint extraction, audience modeling, success criteria, and requirement traceability; handles new work, partial decks, templates, and mixed-content presentations without flattening editable objects unnecessarily.

Use when: the user asks to create, insert, transform, or complete presentation content and expects an editable artifact.

Core checks: Preserve editability; verify object bounds and reading order; inspect rendered slides; test links, media, and animations when relevant; confirm target-platform behavior; and save to a new output unless instructed otherwise.

3. Skill Name: Intake, Intent, and Requirements Formatter

Description: Applies precise, consistent presentation intake and requirements formatting with reusable theme-aware settings, explicit size and position values, alignment, spacing, layering, and visual hierarchy.

Use when: the content exists but needs precise styling, geometry, consistency, brand alignment, or richer PowerPoint effects.

Core checks: Preserve editability; verify object bounds and reading order; inspect rendered slides; test links, media, and animations when relevant; confirm target-platform behavior; and save to a new output unless instructed otherwise.
