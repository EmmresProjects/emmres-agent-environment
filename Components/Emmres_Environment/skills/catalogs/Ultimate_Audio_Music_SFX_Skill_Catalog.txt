How to Use This Catalog

This catalog is a capability blueprint for a powerful audio production agent or coordinated family of specialist agents. It does not implement the skills.

Focused skills can be combined to create songs, scores, instruments, voices, speech, podcasts, SFX libraries, game audio, live shows, immersive works, repairs, mixes, masters, and delivery packages.

Each future skill should preserve sources, identify assumptions, expose controls, produce editable outputs when practical, and include checks for ordinary, boundary, and recovery cases.

Recommended Contract for Every Future Skill

  -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Contract Area                       Expected Design
  ----------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------
  Inputs                              Goal, audience, references, source audio, tempo, key, duration, format, rights, performers, platform, constraints, and delivery specifications.

  Outputs                             Editable session or score, review render, final masters, stems or assets, version label, dependencies, and handoff notes.

  Controls                            Composition, tempo, tuning, instruments, voice, timing, dynamics, timbre, processing, space, variation, quality, and compute limits.

  Checks                              Musical intent, intelligibility, timing, tuning, noise, artifacts, phase, loudness, rights, accessibility, metadata, and format integrity.

  Recovery                            Locate the earliest failing layer, preserve approved work, repair only the responsible component, and rerun linked checks.

  Interoperability                    Document sample rate, bit depth, channels, loudness, timecode, tempo map, tuning, naming, metadata, and interchange formats.
  -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
